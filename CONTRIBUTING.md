# Contributing

The most useful thing you can do right now is run it and say what happened. Nobody but the author has watched this run on a stranger's data, and the README says so.

**Report a first run.** Open an issue with the "First run" template. Say which tool you used (ChatGPT, Gemini, Claude, Claude Code), what it could see (nothing, memory, a project, a vault), how many rows it wrote, one row with its quote, whether the number felt right, and what it did on the next task. Three paragraphs is plenty. If it refused, nagged, or wrote a number without a quote, that is the report.

**Fix the words.** If a rule reads two ways, or a rung's evidence line does not match what you see in your own record, change it and say why. Plain sentences, no semicolons, no taglines. The register is a person explaining a thing they built.

**Add a domain.** [DOMAINS.md](DOMAINS.md) has six. If you work in one that is not there, write the five rungs from your own record, with what each rung looks like in that work.

**Do not add software.** This stays plain text so it survives a change of tool or model. A script that reads the ledgers is welcome in a fork. Here, the files are the product.

MIT. By contributing you agree your words can be used under it.
