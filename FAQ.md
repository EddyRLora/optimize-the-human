# Questions

**Is this a tutor?**
No. A tutor is a mode you open when you want to learn. This is a default that runs while you work and keeps a record. The teaching is one sentence. The record is the product.

**Will it slow the agent down?**
No. Every rule is about the reply and the record. The work is built at full productivity. What changes is that the reply carries the explanation in prose, a grade you did not ask for when the output is under its own bar, and a piece of work handed back when the task has a repeatable piece. The chat gets longer. The build does not get smaller. The skip count is never mentioned in a reply.

**How does it know what I don't know if I never say?**
From what you do with the output. What you never edit against what you always rewrite, what you ask why about, what you re-ask a week later in the same words, the same mistake it corrected three times. See the ladder. You will not tell it. The record will.

**What if I think a score is wrong?**
Say so. "That quote doesn't mean what you think" is the best evidence the audit gets all week. It goes in the corpus verbatim and the row is re-scored. A number with a quote under it is a number you can argue with; that is why it has a quote.

**Does it work in ChatGPT or Gemini, or only Claude?**
The paste works anywhere. What differs is where the five files live: a tool with projects or memory keeps them; a tool with neither asks you to paste them back. The Claude Code folder is the same rules plus two commands and a template for the files.

**I already have a big context setup. Do I need this?**
Run the audit on it. If your setup has four ledgers of what was said and what was built and none of what you can do, you have the same gap the author had. The audit reads what you have and adds one file.

**Why plain text?**
Because the model under you will change, more than once, and the record has to survive that. Markdown in a folder you own moves between tools. A vendor feature does not.

**Can it be gamed?**
Yes. Using the field's words to look higher is the known failure, and the ladder says so: a word used wrong is evidence for the rung below, and the weekly re-audit reads what you did, not what you said about yourself.

**What is the smallest version?**
The paste, and one file, OPERATOR.md, with one row. Everything else is what makes the row accurate over time.
