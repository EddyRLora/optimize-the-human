# 02 Workspace Sync
> Up: [[00 - Index|Agent SOPs]]

**The rule.** One fact lives in many files. When it changes, every copy changes, in the same sitting. A partial update makes the brain lie, and the next session reads the lie with full confidence.

**Routing.** Keep a short map here of which facts live where, and update it as the brain grows. The shape:

| Kind of change | Files that hold it |
|---|---|
| Status of a project, client or application | `CLAUDE.md` current state, `OS/Manual/Start Here.md`, the pillar's index, this session's Conversation Log entry |
| Money or dates | `Start Here`, `Dashboard`, `HEARTBEAT` line |
| A task born or done | its one home (SOP 05), nowhere else |
| A system built | `OS/Manual/What I've Built.md` |
| A rule or preference learned | memory (one file) and the index line |
| A fact proven false | every file that carried it, marked SUPERSEDED with the date, plus a `HEARTBEAT` line |

**Superseding, not deleting.** When a number or a date stops being true, the old line is marked superseded with the date and the new one is written beside it. A find-and-replace on a number is dangerous when the number is coupled to arithmetic elsewhere. Mark it instead and rebuild from the source.

**When reading any file and spotting stale or conflicting information,** fix it or flag it now. Not later.
