# 05 Task Capture
> Up: [[00 - Index|Agent SOPs]]

**Why.** An audit once surfaced thousands of "open items" because tasks were written in a dozen formats across hundreds of files: checkboxes, bullets, status tables, prose imperatives, session steps. No sweep could catch them all, done items sat in open lists, and the same task was captured five times in five files.

**The one rule.** A task has exactly one home. Everything else points to it.

**Homes.** A quick list (one sitting: pay, send, confirm, delete). A deep-work list under its category. One board per client or project, dated, with a superseded banner on any older board the day it is replaced. A done log, where items move the moment they are done and are never deleted.

**The line.**

```
N. [TAG] One plain sentence, action verb first, with the date, amount or gate in the text. (source or id)
```

Four tags only, uppercase: `[RED]` a deadline or money risk; `[GATED]` waiting on a named person or event; `[QUICK]` one sitting; `[STALE]` do or kill.

**What is never a task.** Knowledge (a finding, a rule, a framework: it lives in the Knowledge Base or the SOPs). A fact (it lives in the ledgers). A wish without a verb. A line that only links somewhere else.

**A deferral is a task.** Something cut on purpose and not written to a board as an item with an owner reads as an omission a week later. Write the cut.
