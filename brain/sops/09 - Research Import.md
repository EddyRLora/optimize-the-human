# 09 Research Import
> Up: [[00 - Index|Agent SOPs]]

How anything from outside enters the brain: an article, a PDF, a screenshot, a transcript, another assistant's output.

1. **Keep the source.** Save the original (or its link and date) in `OS/Knowledge Base/<topic>/`. A finding without its source is a rumor in a week.
2. **Extract, then attribute.** Write what it says in your own words, with the claims that matter pulled out and each one marked as what it is: a measurement, a study (with sample size and design), an opinion, marketing. Never paste a third party's prose into the Corpus. The Corpus is the human's words only.
3. **Connect it.** One line on what in the brain it touches: which task, which decision, which rule. An import that connects to nothing is noise and goes to the archive.
4. **Verify before it moves anything.** A number read in a screenshot is checked at the source before it changes a file in the brain. Names of tools another assistant gave you are searched for before they are repeated.
5. **Screenshots** are read for what is relevant to the work and connected back, not summarized.

**Volume is not truth.** Twenty sources agreeing is twenty sources. It is not evidence until one of them measured something.
